## Phase Goal

Roadmap goal (verbatim): The TUI is customizable through three TOML files in `~/.config/rockettui/`, with built-in defaults.

User story: not framed (see plan 02-01).

This plan delivers ROADMAP Phase 2 success criterion 2 ("User changes the keymap preset, and rebinds a key in keymap.toml, and the behavior changes"). It runs in parallel with plan 02-02.

Parallel-safety note: plan 02-02 runs at the same time and never edits src/config/*, src/input/*, src/action.rs, src/app/update.rs or scripts/smoke_pty.py; this plan never edits src/app/mod.rs, src/lib.rs, src/test_util.rs or any src/ui file. Tests here may use `crate::test_util::{app_with_config, temp_config_dir, press, render_to_string}` (all exist after plan 02-01) but must not add helpers to src/test_util.rs.

<objective>
Load keymap.toml per mode on top of the chosen preset, with a curated action vocabulary, `none` unbinding, `cmd:` command bindings, the vim-extras preset, and load-time detection of every keymap problem (bad notation, unknown action or command, duplicates, prefix clashes, self-lockout, text-eating sequences).

Purpose: CONF-04 and CONF-05 (plus their CONF-03 error classes); D-04, D-05, D-06, D-07, D-14.
Output: src/input/actions.rs, src/config/keymap.rs, `Trie::remove`/`clashes`/`entries`, `Keymap::bind`/`unbind`/`clashes`/`bindings`, `vim_extras_bindings`, Action variants `FocusNext`, `FocusPrev`, `RunCommand`, and the pty scenario config_keymap.
</objective>
