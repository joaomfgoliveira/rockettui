2. `def sidebar_rows(screen, width=28)`: the text between the left and right sidebar borders for screen rows 1..rows-3, with the cursor marker column stripped and trailing spaces removed. `def selectable_index(rows, name)`: walk the rows, skip blank rows and the headers `Unread`, `Folders`, `Recent`; folder rows (fold glyph first) and room rows are selectable; return the selectable index of the first room row whose last whitespace-separated token, without its kind glyph, equals name; None when absent. `def open_room_named(fd, buf, name)`: type Ctrl-w (`\x17`) and `h`, then `gg`; compute the index on a fresh Screen; type `j` that many times, then `\r`; read_until (10 s) the status row (screen row nrows-2) contains name; SmokeFail otherwise.

3. `scenario_docker_read`: env = docker_env(project); spawn with extra_env=env (no server_url, so no mock); wait_ready(fd, buf, room=b"rt-public") with a 20 s budget; on the sidebar require rt-public, rt-private, alice, secrets, rt-team and rt-discussion, plus the Favorites folder; when src/api/fixtures/docker/preferences.json holds a non-default category, require its name too; SmokeFail if a room row named bob exists. open_room_named("rt-public"); read_until the Screen contains `seed message 129` and `[attachment: report.pdf]`; then repeat up to 6 times: type `gg`, wait 1.5 s while reading, stop when the Screen contains `* joined the room`; then type `gg` once more and read_until the status row contains `Beginning of history`. open_room_named("secrets"); read_until `encrypted, not supported`. open_room_named("alice"); read_until any message row is drawn (the pane no longer shows `Loading…` or `No messages yet`). Type `:q` and `\r`; exit code 0. SmokeFail if the token value from env appears anywhere in the pty output. Register it in SCENARIOS.
