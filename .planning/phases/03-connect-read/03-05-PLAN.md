## Phase Goal

Roadmap goal (verbatim): User authenticates with a PAT and reads real rooms and history from a local Docker Rocket.Chat.

User story: not framed (see plan 03-01).

This plan completes ROADMAP criterion 1 (credentials from env var or config) and the first half of criterion 5 (warn about a config file with credentials that is not chmod 600).

<objective>
Let the user keep server_url, user_id and token in config.toml (environment variables still win per key), validate them with the Phase 2 error pipeline, and warn persistently, without blocking, when a config.toml holding the token is readable by others or when the token would travel in clear to a remote host.

Purpose: AUTH-01 (file half), AUTH-02, part of AUTH-03; D-01, D-02, D-03, D-04, D-07.
Output: FileConn and parse_file, per-key precedence, the file mode in Sources, a redacting Sources Debug, Config/App warnings, status and stderr output, pty scenarios config_creds and perm_warning.
</objective>
