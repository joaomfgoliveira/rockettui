## Phase Goal

Roadmap goal (verbatim): User composes and sends messages to the open room.

User story: not framed (see plan 04-01).

This plan implements D-20, which the user added after the plan check: `:q` while any message is undelivered (Queued, Sending, Failed or Unconfirmed, in any room) shows a one-line status message without message text and does not quit; a repeated `:q` or `:q!` quits anyway. It replaces research default (d), under which a quit dropped undelivered messages silently. It is its own plan in wave 5 because it shares src/app/mod.rs with plan 04-05 and src/app/command.rs and scripts/smoke_pty.py with plan 04-06, so it cannot run beside either of them.

<objective>
Make `:q` warn instead of quitting while messages are undelivered, keep a repeated `:q` and `:q!` as the way out, and keep every pty scenario's exit deterministic now that `:q` can refuse.

Purpose: MSG-02 with D-20 (and D-14 for the warning text).
Output: App.quit_warned, App::undelivered_count, the guarded cmd_quit, cmd_force_quit (`q!`, `quit!`), the disarm rule in execute, the quit_undelivered pty scenario, the wait_confirmed helper and the quit-path changes of the sending scenarios.
</objective>
