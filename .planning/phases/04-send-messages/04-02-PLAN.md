## Phase Goal

Roadmap goal (verbatim): User composes and sends messages to the open room.

User story: not framed (see plan 04-01).

This plan makes a failed send recoverable from the keyboard (D-06) and makes a lost response safe to retry (D-07, D-15 reconcile). Plan 04-03 draws the failed and unconfirmed markers in parallel; this plan's checks use the status line, the mock's request log and the swapped author.
