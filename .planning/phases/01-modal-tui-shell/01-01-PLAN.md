## Phase Goal

Roadmap goal (verbatim): A runnable ratatui app with the sidebar + messages + input layout, fake rooms, and Normal/Insert/Command modes.

User story: not framed. The ROADMAP `**Goal:**` line is not in "As a / I want to / so that" form, and the planner does not invent one. Run `/gsd-mvp-phase 1` if story framing is wanted; it does not change this plan's tasks.

This plan is the **first half of the Walking Skeleton** (see `SKELETON.md` in this directory). By author decision (plan-check iteration 2, B3) the old single skeleton plan is split in two so that no plan exceeds about 15 files: this plan builds the headless core (crate, model, keys, keymap data, data seam, reducer, `:` commands) and leads with a headless tracer that threads seed Actions -> reducer -> keymap -> j/k -> `:q` -> `should_quit` through the real functions; plan 01-02 leads with the binary tracer (`cargo run` -> layout -> j/k -> `:q` -> restored terminal) on top of it.

Scope note (file count): 14 files in `files_modified`, and that count includes the cargo-generated Cargo.lock, so this plan creates and commits exactly 14 files, below the 15-file blocker threshold (plan-check iteration 2 of the re-plan counted 15 while the lockfile was committed but unlisted). To get there, the two test helpers `press` and `app_80x24` live in an inline `#[cfg(test)] pub(crate) mod test_util { ... }` block at the end of src/lib.rs, a file this plan writes anyway, instead of in a separate src/test_util.rs. Plan 01-02, which already owns src/test_util.rs for `render_to_string`, moves that block into the file unchanged; the crate path `crate::test_util::press` is identical before and after, so no test written here changes. No other file can move: the tracer reaches j/k through src/app/sidebar.rs and `:q` through src/app/command.rs, and every remaining file is one module of the headless core (or cargo's scaffold: Cargo.toml, Cargo.lock, .gitignore). Cargo.lock is written by the `cargo add` commands of task 1 step 1, never edited by hand, and no other Phase 1 plan regenerates it (no later plan adds a crate), so it causes no wave overlap; task 1 proves it is committed with `git ls-files --error-unmatch Cargo.lock` and `git cat-file -e HEAD:Cargo.lock`.

Stage B, model, keys and data seam (no terminal).

2. Action (src/action.rs). `#[derive(Clone, PartialEq)] pub enum Action` with exactly: `MoveDown, MoveUp, EnterCommand, Cancel, InsertChar(char), DeleteBack, ExecuteCommand, Quit, Key(crossterm::event::KeyEvent), Resize(u16, u16), Clock(i64), Paste(String), RoomsLoaded(Vec<Room>), FoldersLoaded(Vec<Folder>), MessagesLoaded(RoomId, Vec<Message>)`. Clock carries seconds since the Unix epoch; Key, Resize, Clock, Paste and the *Loaded variants are event Actions that no keymap row may bind. It gets no Debug in this task, neither derived nor written; task 2 writes the hand-written redacting one, so no build of this plan can print typed, pasted or message text (T-01-03).

3. Domain types and data seam (src/data/mod.rs with `pub mod fake;`, src/data/fake.rs; D-12, D-13). `pub struct RoomId(pub String)` and `pub struct FolderId(pub String)` derive Clone, Debug, PartialEq, Eq, Hash, PartialOrd, Ord. `pub enum RoomKind { Channel, PrivateGroup, Discussion, Team, DirectMessage }` derives Clone, Copy, Debug, PartialEq, Eq. `pub struct Room { pub id: RoomId, pub name: String, pub kind: RoomKind, pub encrypted: bool, pub unread: bool, pub last_activity: i64 }` derives Clone, Debug, PartialEq. `pub struct Folder { pub id: FolderId, pub name: String, pub room_ids: Vec<RoomId> }` derives Clone, Debug, PartialEq (membership by room id). `pub struct Message { pub id: String, pub room_id: RoomId, pub author: String, pub ts: i64, pub body: String }` derives Clone and PartialEq only (task 2 adds its hand-written Debug). data/fake.rs: `pub fn seed() -> Vec<Action>` returning `RoomsLoaded`, then `FoldersLoaded`, then one `MessagesLoaded` per room. In this task seed 3 rooms in this order: general (Channel), random (Channel), alice (DirectMessage), a few plain-text messages each, and an empty folder list; task 3 grows it to the full D-13 dataset with general still first.

4. App state (src/app/mod.rs). `pub mod command; pub mod sidebar; pub mod update;`. `#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)] pub enum Mode { Normal, Insert, Command }` with `pub fn label(self) -> &'static str` returning "NORMAL", "INSERT", "COMMAND". `#[derive(Clone, Copy, Debug, PartialEq, Eq)] pub enum Focus { Sidebar, Messages, Input }`. `pub enum StatusMsg { Info(String), Error(String) }` with no Debug derive (an Error can echo the typed command line; tests check it with `matches!`). `pub const MAX_CMDLINE: usize = 256;`. `pub struct App { pub mode: Mode, pub focus: Focus, pub prev_focus: Focus, pub size: ratatui::layout::Size, pub clock_secs: i64, pub rooms: Vec<Room>, pub folders: Vec<Folder>, pub messages: HashMap<RoomId, Vec<Message>>, pub current_room: Option<RoomId>, pub sidebar: sidebar::SidebarState, pub cmdline: String, pub status_msg: Option<StatusMsg>, pub keymap: Keymap, pub should_quit: bool }` with no Debug derive. Methods: `pub fn new(size: Size) -> Self` (Normal mode, Focus::Sidebar, clock_secs 0, no rooms, `default_keymap()`); `pub fn with_fake_data(size: Size) -> Self` (App::new, then every `data::fake::seed()` Action through `update::update`; used by tests and snapshots); `pub fn input_rows(&self) -> u16` returning 1 (plan 01-06 derives it from the input buffer); `pub fn current_room_name(&self) -> Option<&str>`.

5. Reducer (src/app/update.rs). `pub fn update(app: &mut App, action: Action)` is the only state-transition function. Key: clear `status_msg`; `let chord = crate::input::key::normalize(ev)`; if `app.keymap.lookup(app.mode, &[chord])` returns an Action, recurse with a clone of it; else, when the mode is not Normal and the chord code is a Char without CONTROL or ALT, recurse with `Action::InsertChar(c)` (text-entry fallback); else ignore. Bindings never live in code: no per-mode match on key codes (D-07). RoomsLoaded / FoldersLoaded store the data then call `sidebar::on_rows_changed(app)`. MessagesLoaded inserts into `app.messages`. Resize sets `app.size = Size::new(w, h)` and nothing else. Clock(t) sets `app.clock_secs = t` in every mode and nothing else (the run loop of plan 01-02 is the only producer; the reducer never reads a clock). MoveDown / MoveUp call `sidebar::apply_motion(app, &action, None)` when focus is Sidebar. EnterCommand sets Mode::Command and clears cmdline. Cancel (D-17): in Command clear cmdline and set Normal; in Normal clear status_msg. InsertChar(c) in Command appends when cmdline has fewer than MAX_CMDLINE chars. DeleteBack in Command pops one char, or returns to Normal when cmdline is empty. ExecuteCommand takes the cmdline with `std::mem::take`, sets Normal and calls `command::execute(app, &line)`. Paste is ignored in Normal and Command here (plan 01-06 adds Insert and Command paste). Quit sets `should_quit`.

6. Commands (src/app/command.rs; D-16). `pub struct CommandDef { pub names: &'static [&'static str], pub run: fn(&mut App, &[&str]) -> Result<(), String> }`; `pub const COMMANDS: &[CommandDef]` holding one entry with names `["q", "quit"]` and `run: cmd_quit` (sets should_quit). `pub fn execute(app: &mut App, line: &str)`: trim; an empty line is a no-op; the first whitespace token is the name, the rest are args; run the first CommandDef whose names contain it and turn `Err(msg)` into `StatusMsg::Error(msg)`; an unknown name sets `StatusMsg::Error(format!("Unknown command: {name}"))`.
