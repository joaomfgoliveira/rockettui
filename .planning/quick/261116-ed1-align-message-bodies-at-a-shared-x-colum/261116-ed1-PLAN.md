<objective>
Align every message body in the messages pane (Compact layout, D-10) at one shared x column per room. The column is the display width of the widest sanitized author among the open room's messages, plus the existing `HH:MM ` prefix and two-space separator, so a body no longer starts further left for short usernames. Wrapped lines keep their hanging indent at that same column. On narrow panes the author column is capped so the body keeps at least `MIN_BODY` columns, and over-wide authors are truncated with an ellipsis.

Purpose: one body column makes the conversation easier to scan, and it keeps the reducer's row model (`row_starts`/`view`, D-04) identical to what is drawn.
Output: updated `src/ui/wrap.rs`, `src/app/messages.rs`, `src/ui/messages.rs`, two regenerated insta snapshots, new unit and render tests.

**Cap rule (how and why):** `col = min(room_author_col, width - (5 + 1 + 2 + MIN_BODY))`, using saturating subtraction and the message's real `HH:MM` width (always 5). At the default 80x24 layout the inner pane width is 50, so names up to 32 columns render in full. Below an inner width of 19 the column drops to 0 and the author is omitted; the body keeps `MIN_BODY`, and as before the paragraph clips the overflow. The cap is applied inside `render_rows`, so the renderer and `message_rows` (the reducer) always use the same capped value.

**Files outside the description:** `src/app/messages.rs` has to change because `row_starts` calls `message_rows`. If it does not get the same author column, scroll math and drawing disagree.
</objective>
